# E-commerce Revenue & Orders Performance Analysis
## Summary
This project analyzes revenue and order performance of Brazilian e-commerce transaction data. An ETL pipeline was built using Python, SQL was used to perform analyses, and a Power BI dashboard was built to track performance.

Data Source - https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Tools
- SQL (PostgreSQL)
- Python (pandas)
- Power BI 
- Jupyter Notebook 
- VS Code

## Key Findings:
- Total revenue is approx. $13.55 and the top 3 states that contribute the most revenue are: SP - 38.31% ($5191829.48), RJ - 13.39% ($1815534.97), MG - 11.66% ($1580228.93)
- Beleza Saude has 9669 orders with $1258591.44 revenue accounting for 9.29% of total revenue
